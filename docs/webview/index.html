手机端会话列表展开 / 收起后跳回顶部会话Bug
手机端展开会话列表再收起，重新打开时列表总是回到最顶部，之前滑到的位置丢失。
复现
手机端打开会话列表 → 往下滑 → 收起列表 → 再展开，列表回到顶部。
疑似原因
SessionsScreen 失焦时直接返回空容器， SessionsScreenContent 随之卸载，列表滚动位置丢失。见 packages/app/src/screens/sessions-screen.tsx:64。
笔记里的链接没用外部浏览器打开笔记Bug
笔记里的链接点开后应该走手机的外部浏览器，目前的表现像是在 App 内打开了。
期望
默认用手机浏览器打开；另加一个偏好项选择打开方式——外部浏览器（默认）或 App 内 webview（内容浏览）。
涉及位置
笔记链接统一走 openExternalUrl（ packages/app/src/utils/open-external-url.ts），native 下调 Linking.openURL；详情页内联链接见 packages/app/src/components/markdown/renderer.tsx:476，链接列表见 packages/app/src/notes/note-links-section.tsx:54。需在真机确认实际打开位置。
手机端自己发的消息复制按钮点不到会话Bug
手机端自己发送的消息，复制按钮原来一直显示；现在只有点中 / 选中时才出现，手指一离开又消失，导致点不到，无法复制自己发的消息。
复现
手机端打开含自己消息的会话 → 消息下方复制按钮不常显 → 点一下消息，按钮短暂出现 → 手指离开即消失 → 点不到。
期望
恢复常显；或点击消息后保持显示，直到再次点击 / 完成复制，不能依赖手指停留。
疑似原因
可见性走了 hover / 按压态。见 packages/app/src/components/message.tsx:459 （showTrailingRow = !isPending && hasText && (isCompact || isNative || isHovered)） 与 message.tsx:552-580 的 trailing row。需确认该平台 isNative / isCompact 是否为 true；按 docs/hover.md，触屏控件应常显，不能依赖 hover。
手机端会话列表时间覆盖三点菜单会话Bug
会话 / 工作区列表行新增了时间显示，但时间占用了原来三点菜单（kebab）的位置，三点菜单被覆盖、点不到。
复现
手机端打开会话列表 → 观察行尾：时间与三点菜单重叠 / 冲突，三点菜单无法正常点击。
建议
把时间放到服务器（host）名称后面，保留原来的三点菜单在行尾。
疑似原因
sidebarWorkspaceTrailing 默认改成 "timestamp"（packages/app/src/hooks/use-settings/storage.ts:153）， 时间与触屏常驻 kebab 争用同一个 trailing slot。相关： packages/app/src/components/sidebar/workspace-trailing/index.tsx、 packages/app/src/components/sidebar/sidebar-workspace-row-content.tsx 的 resolveTrailingActionVisibility。
